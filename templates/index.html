Project Summary

Capstone Prototype

AEFAS demonstrates how lecturers can upload teaching resources, generate AI-assisted formative assessment questions, review them in a human-in-the-loop workflow, store approved items in a centralized bank, and export questions to Moodle-ready formats such as GIFT and XML.

1

3

Lecturers edit, refine, approve, or discard questions before they enter the item bank.

System View

Settings / Architecture

Frontend

HTML / CSS / JavaScript

Server-rendered Flask (Jinja2) pages — generator, review dashboard, and auth screens — with live filtering and approve/discard controls.

Backend

Flask

Implemented API and route layer handling authentication, PDF upload/indexing, generation, dashboard CRUD, export, and Moodle push.

AI Layer

TinyLlama-1.1B-Chat (local)

Runs fully offline via HuggingFace Transformers (CPU/CUDA/MPS) — no external API calls. Generates questions with a template-based fallback.

Retrieval Layer

RAG — PyMuPDF + MiniLM + FAISS

Uploaded PDFs are extracted, chunked, embedded, and indexed in FAISS, grounding every generated question in real course content.

Database

SQLite (SQLAlchemy)

Implemented item bank storage for users, questions, Moodle config, and export logs.

Deployment

Linux / Local (Docker planned)

Runs on the local Flask dev server today; containerized deployment for institutional hosting is still future work.

Security

Session Auth (OAuth2 / SSO planned)

Login is implemented via Flask-Login with hashed passwords. OAuth2/SSO and role-based access are still future work.

Prototype Note

Functional Full-Stack Prototype

Real backend, real local AI model, real database, real login, and a working Moodle export/push pipeline are included. Containerized deployment and OAuth2/SSO remain future work.

Moodle Import Guide

This prototype demonstrates how approved questions could be exported into Moodle-compatible formats.

  1. Open Moodle and go to the Question Bank.
  2. Select the Import option.
  3. Choose either GIFT or Moodle XML format.
  4. Upload the exported file from AEFAS.
  5. Assign or confirm the destination category.
  6. Complete the import process.
