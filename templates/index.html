Project Summary

Capstone Prototype

AEFAS demonstrates how lecturers can upload teaching resources, generate AI-assisted formative assessment questions, review them in a human-in-the-loop workflow, store approved items in a centralized bank, and export questions to Moodle-ready formats such as GIFT and XML.

1
Upload Academic Documents

Subject descriptions, outcomes, rubrics, and sample assessments are added to the RAG knowledge base.

2
Generate Questions

The system creates draft assessment items using selected topic, category, difficulty, and grounded context.

3
Review and Approve

Lecturers edit, refine, approve, or discard questions before they enter the item bank.

Moodle Import Guide

This prototype demonstrates how approved questions could be exported into Moodle-compatible formats.

  1. Open Moodle and go to the Question Bank.
  2. Select the Import option.
  3. Choose either GIFT or Moodle XML format.
  4. Upload the exported file from AEFAS.
  5. Assign or confirm the destination category.
  6. Complete the import process.
